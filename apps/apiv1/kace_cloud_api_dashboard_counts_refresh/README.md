# kace_cloud_api_dashboard_counts_refresh

Scheduled multi-tenant Lambda that keeps the dashboard count materialized views approximately one minute fresh. Every minute, EventBridge fires a cron rule (`cron(* * * * ? *)`) that invokes an OrchestratorHelper Lambda, which fans out one invocation per tenant. Each tenant invocation uses `withTenantContext` to inject the tenant database connection, then `EventController.run()` runs `REFRESH MATERIALIZED VIEW CONCURRENTLY` for `mv_dashboard_state_counts`, `mv_dashboard_group_counts`, and `mv_dashboard_responsible_counts` independently, collecting any per-matview failures without aborting the remaining refreshes. Invocation path: EventBridge Schedule → OrchestratorHelper (per-tenant fan-out) → this Lambda (`withTenantContext` → `EventController.run()`).
